### 关于这个项目的真实情况
这就是我大一开学一个半月，花了大概 12 天时间搓出来的一个练手项目，本质上是一个能跑通闭环的 MVP，不是工业级代码。
目前存在的明显不足：
1. 状态机写得很糙。按键的 FSM 里面用了裸全局变量，比如 cnt 和 keystate。状态切换的边界条件卡得比较死，如果后面加上双击、多击，现在的结构很容易崩。
2. 没做封装。为了快速验证逻辑，没有把全局变量用结构体私有化，以后如果要加更多传感器，代码维护起来会很麻烦。
3. 外设不全。因为时间有限，我刻意跳过了 I2C、SPI、ADC 这些，只留了验证底层架构必须的 UART、GPIO 和 TIM。
现阶段情况与后续计划：
我是个大一新生，接下来几周马上要面临高数等重要科目的期中考试，所以这个单片机项目暂时封箱，不再加新功能了。
我搞这个项目的核心目的，不是为了用单片机做产品，而是为了搞懂“软硬结合”的底层逻辑。在 C 语言和裸机上写 RingBuffer、非阻塞状态机和临界区保护，其实是在用软件模拟硬件的数据流调度。
等考完试，寒假我会直接转战 FPGA 和 Verilog。
在这个单片机项目里搞懂的 FIFO 缓冲、硬件状态机和译码器思维，接下来我会用真正的硬件语言在 FPGA 上重写一遍，去搞懂真正的跨时钟域同步（CDC）和流水线架构。再往后，我的目标是自己手搓一个 RISC-V 核，往 AI 加速器和软硬协同方向走。
感谢 AI 辅助工具（Copilot）帮我补齐了不少规范语法，也感谢自己熬过了修环境、指针乱飞和时序失控的坑。
